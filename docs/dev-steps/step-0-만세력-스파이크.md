# AI 사주 서비스 — 만세력 계산 엔진 검증 스파이크

## 배경

AI 사주 서비스 MVP를 준비 중이다.

- 서비스 구조: 사용자 입력(생년월일시) → 만세력 계산 → GPT가 에세이 형식의 사주 리포트 생성 → DB 저장
- 사주 계산은 외부 API 대신 **오픈소스 라이브러리를 서비스에 내장**하는 방향으로 결정했다.
- 본격 개발 전에 라이브러리 정확도를 검증하는 스파이크를 먼저 진행한다.

**이 스파이크의 검증 범위는 원국 8글자에 그치지 않는다.**
리포트는 "작년부터 올 초까지 편관과 형살이 겹쳐서 힘들었다", "9월까지는 내실을 다지고
10월에 관성이 들어올 때 움직여라" 같은 문장을 쓴다. LLM에는 명식 JSON만 주고 창작을 금지하는
정책이므로, 이런 문장에 필요한 값이 **전부 계산 결과에 들어 있어야 한다.**
신살·대운·세운·월운이 빠지면 LLM이 지어내는 수밖에 없다.

## 작업 요청

1. 후보 라이브러리 조사 및 설치 (TypeScript/Node 기준)
   - lunar-javascript / lunar-typescript (6tail)
   - 국내 개발 만세력 npm 패키지
   - 후보 2~3개로 압축
   - **선정 기준에 아래 2번 출력 항목의 지원 범위를 포함할 것.**
     원국만 계산되고 신살·대운을 못 주는 라이브러리는 감점이며,
     직접 구현해야 하는 항목과 그 난이도를 함께 정리할 것

2. 검증 스크립트 작성
   - 입력: 생년월일시(**시:분 단위** — 시주 경계 판정에 분이 필요), 성별, 양력/음력 여부
   - 출력: 명식 JSON — 아래 항목을 모두 포함
     - **원국**: 년/월/일/시주 8글자, 오행 분포, 십신, 지장간
     - **신살**: 형·충·파·해, 역마, 도화, 백호 등 (리포트 문장에 직접 인용됨)
     - **대운**: 현재 대운 + 직전 대운 (과거 흐름을 공감하는 서사에 필요)
     - **세운**: 직전 2년 + 대상 연도(2026)
     - **월운**: 대상 연도 12개월 ("9월까지", "10월 넘어갈 즈음" 같은 월 단위 조언에 필요)
   - 각 항목은 어떤 십신/신살이 어느 강도로 작용하는지 **값으로** 표현할 것 (문장 생성은 LLM 몫)

3. 샘플 30건 대조 검증
   - 유명 만세력 서비스(포스텔러, 만세력 사이트 등) 결과와 비교
   - 반드시 포함할 경계 케이스:
     - 입춘 직전/직후 출생 (년주 경계)
     - 절기 당일 출생 (월주 경계)
     - 밤 23시~01시 출생 (야자시/조자시 처리)
     - 음력 윤달 출생
     - 1987~1988년 서머타임 기간 출생
   - 한국 표준시(동경 135도) vs 실제 경도 보정을 라이브러리가 어떻게 다루는지 확인

4. 결과 정리
   - 라이브러리별 정확도 비교표
   - **출력 항목별 지원 여부 표**: 원국 / 십신 / 지장간 / 신살 / 대운 / 세운 / 월운
     (미지원 항목은 자체 구현 난이도와 참고할 계산 규칙을 함께 적을 것)
   - 한국식 명리 관행(야자시 등) 지원 여부
   - 최종 추천 1개 + 근거

5. 추천 라이브러리를 감싸는 계산 모듈 설계 초안
   - 입력(생년월일시, 성별, 양/음력) → 출력(명식 JSON)
   - 이 JSON은 이후 GPT 리포트 생성 시 프롬프트 context로 들어갈 예정이므로, LLM이 읽기 좋은 구조로 설계할 것
   - 리포트가 쓸 어휘(편관, 식상, 역마, 도화, 편재, 겁재, 인성, 형살 등)가
     JSON의 **키 또는 값으로 그대로 등장**하게 설계할 것. 그래야 LLM이 창작 없이 인용할 수 있다

## 제약

- 계산은 100% 결정론적이어야 함 (같은 입력 = 항상 같은 출력, 계산에 LLM 사용 금지)
- 런타임에 외부 API 호출 없이 동작해야 함 (절기 데이터가 필요하면 내장할 것)
- 라이브러리 라이선스가 상용 서비스에 사용 가능한지 확인할 것
- 리포트 문장이 참조할 모든 명리 개념은 이 JSON에 값으로 존재해야 함
  (STEP 2의 "명식 데이터를 벗어난 창작 금지" 제약과 직결된다)
