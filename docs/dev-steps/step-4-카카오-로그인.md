# AI 사주 서비스 — STEP 4: 카카오 로그인

## 프로젝트 컨텍스트

AI 사주 MVP. Next.js 풀스택 + Prisma/PostgreSQL.
핵심 루프(입력→명식→리포트 생성→조회)는 동작 중이다.

퍼널 정책: 로그인은 첫 화면이 아니라 "전체 리포트 보기(결제)" 직전에 요구한다.
비로그인으로 사주 입력과 무료 티저까지 이용 가능해야 한다.

## 작업 요청

1. Auth.js(NextAuth v5) + Kakao Provider 연동
   - User 테이블(kakaoId unique)과 연결, 세션 전략은 JWT
   - 카카오 개발자 콘솔 설정 항목(리다이렉트 URI 등)을 단계별로 안내할 것

2. 비로그인 → 로그인 전환 처리
   - 비로그인 상태에서 만든 SajuProfile(userId null)을 로그인 완료 시점에 해당 User로 연결(merge)
   - 구현 방식: 프로필 id를 쿠키/세션에 보관했다가 로그인 콜백에서 연결

3. 접근 제어
   - 사주 입력, 명식 확인, 무료 티저: 비로그인 허용
   - 전체 리포트 조회, 마이페이지(내 리포트 목록): 로그인 필수
   - 로그인 후 원래 보던 페이지로 리다이렉트

4. 마이페이지: 내 사주 프로필 + 리포트 목록

## 검증

- 비로그인 입력 → 로그인 → 프로필이 계정에 연결되는지 확인
- 로그아웃 후 전체 리포트 접근 시 로그인 페이지로 유도되는지 확인
