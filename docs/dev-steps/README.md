# AI 사주 서비스 MVP — 단계별 개발 프롬프트

각 STEP 파일의 내용을 **순서대로 새 Claude Code 세션에 붙여넣어** 진행한다.
각 프롬프트는 이전 대화를 몰라도 되도록 자체 컨텍스트를 포함하고 있다.

## 핵심 설계 결정 (모든 단계에서 유지)

- **만세력은 내장 라이브러리로 계산** — 런타임 외부 API 호출 없음, 계산에 LLM 사용 금지
- **명식 JSON은 서사에 필요한 데이터를 모두 포함** — 원국 8글자 + 오행/십신/지장간 + 신살 + 대운/세운/월운.
  리포트 문장이 언급하는 모든 명리 개념은 이 JSON에 값으로 존재해야 한다 (LLM 창작 금지 원칙과 직결)
- **리포트는 1회 생성 후 영구 저장** — 사용자 재생성 불가, `(sajuProfileId, productCode)` unique
- **비동기 상태머신** — `PENDING → GENERATING → COMPLETED / FAILED`, 자동 재시도 3회
- **리포트는 에세이/편지 형식** — 소제목·번호 없는 한 편의 긴 글. 단락 배열로 저장하고
  promptVersion / model / 명식 원본을 함께 기록 (섹션 카드 UI 아님)
- **결제 웹훅 + 서버 검증이 유일한 생성 트리거** — 프론트 콜백은 신뢰하지 않음
- **퍼널**: 비로그인 입력 → 무료 티저(동일 보이스 300자) → 전체 보기 시점에 로그인 + 결제
